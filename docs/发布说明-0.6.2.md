# 0.6.2 发布说明（2026-10-03）

本次发布汇总参考项目更新吸收、推理期间管理界面响应修复、国内外低价路由，以及逻辑审查发现的边界修复。后端与前端版本统一为 0.6.2，数据库 schema 为 v8，不新增运行时依赖。

## 请求与调度逻辑

- 并发名额由账号池锁保护，只有成功占位才能发送请求和释放名额；满载最多异步等待 10 秒，超时明确返回 503。无上限时仍保留计数，热修改上限不会丢失已有名额。所有协议均只占用“连接建立至首字节”的窗口。
- 健康兜底不再绕过积分耗尽与连败临时摘除；短期冷却探测仍沿用原有边界，超过 30 秒的冷却由网关拒绝。
- Chat 流式和非流式统一先建立连接、按错误分类换号，再透传或聚合。失败换号排除初始账号，最多一次；请求级错误保持原策略，已经输出内容不自动重发。
- 失败异常携带实际使用账号和是否已处置的标记，第二次失败正确归因，不重复惩罚初始账号或覆盖其 Retry-After 冷却。
- Chat 与 Messages 校验 finish_reason，缺失时拒绝伪造正常完成；长度限制等未完成状态以 incomplete 记账。三协议正常终态前完成记账，随后正常关流不会重复记录 aborted，并显式关闭上游迭代器。
- 设置先全部校验和规整，一次事务保存，成功后重载内存配置；并发保存串行化。SQL 写入失败回滚同批设置，数值 0 正确保留“不限制”语义。

## 性能

- SSE 心跳转发最多缓存 32 个待发块，慢客户端会反压上游；取消时等待后台读取任务结束并关闭内部生成器。
- 历史正文体积在 SQL 中聚合，只返回统计数值，避免同时把所有图片、输入、输出及思考原文读入 Python 内存；原文保留策略不变。
- 0.6.1 已将同步 token 刷新、鉴权及用量写入移至线程，管理查询使用独立 WAL 快照；v8 的统计覆盖索引减少正文页扫描。

## 价格规则

候选必须符合账号健康和模型可用条件；优先空闲连接名额，再按同一模型的区域目录报价从低到高选择，同价内比较实测成本。会话粘性不能绕过更便宜的候选，失败换号沿用同一规则。未知报价不等于免费，usage 缺少 credit 不学习免费成本。

目录报价较高但近期实测免费的账号，可能被目录低价候选排除；免费与未知观测仍在同一优选层。这是当前明确保留的策略取舍。实测免费优先和未知成本探索预算尚未实现，不能把单次零扣费当作永久免费。
